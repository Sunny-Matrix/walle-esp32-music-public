# WALI AI 学習コンパニオン

（[中文](README.md) | [English](README_en.md) | 日本語）

WALI は ESP32-S3 を中心にした AI 学習コンパニオンです。クラウド大規模モデルとの音声対話を、ディスプレイ、マイク、スピーカー、タッチ入力、LED、サーボ、音楽再生、スマートフォン向け Web ページと組み合わせます。

## 主な機能

- 起動、聴取、思考、発話、再生、終了状態を持つ音声インタラクション。
- 数学、科学、英語、日本語に対応した4段階の分步学習ガイド。
- 学習内容、つまずき、成長フィードバックを学習記録ページに表示。
- ホーム画面で天気、時刻、位置情報を表示。
- 音声、画面、目のライト、短い動作による感情サポート。
- 音楽検索、FFmpeg変換、ローカルキャッシュ、デバイス再生。
- デバイス制御ページと学習記録ページを分離。

## ディレクトリ

```text
main/                         ESP32-S3 ファームウェア
main/boards/robot-s3/         WALI ハードウェア設定
web-control/                  デバイス制御ページ
web-learning/                 学習記録ページ
music-api-cos/                音楽サービス
docs/                         通信・開発資料
```

## クイックスタート

ESP-IDF 5.4 以降を使用します。

```powershell
idf.py set-target esp32s3
idf.py build
idf.py -p COM14 flash monitor
```

秘密情報、APIキー、トークン、データベース、証明書、ローカルパスはローカル環境ファイルで管理し、リポジトリにコミットしないでください。
